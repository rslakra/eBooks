## Combinatorics and Statistics

Binomial coefficients are of importance in [combinatorics](https://en.wikipedia.org/wiki/Combinatorics), because they provide ready formulas for certain frequent counting problems:

- There are $\binom{n}{k}$ ways to choose $k$ elements from a set of $n$ elements. See [Combination](https://en.wikipedia.org/wiki/Combination).
- There are $\binom{n+k-1}{k}$ ways to choose $k$ elements from a set of $n$ elements if repetitions are allowed. See [Multiset](https://en.wikipedia.org/wiki/Multiset).
- There are $\binom{n+k}{k}$ [strings](https://en.wikipedia.org/wiki/String_(computer_science)) containing $k$ ones and $n$ zeros.
- There are $\binom{n+1}{k}$ strings consisting of $k$ ones and $n$ zeros such that no two ones are adjacent.[4]
- The [Catalan numbers](https://en.wikipedia.org/wiki/Catalan_number) are $\frac{1}{n+1}\binom{2n}{n}$.
- The [binomial distribution](https://en.wikipedia.org/wiki/Binomial_distribution) in [statistics](https://en.wikipedia.org/wiki/Statistics) is $\binom{n}{k}p^k(1-p)^{n-k}$.

### Formulas at a Glance

| Counting problem | Formula |
| :--- | :--- |
| Choose $k$ elements from a set of $n$ elements | $\binom{n}{k}$ |
| Choose $k$ elements from a set of $n$ elements, repetitions allowed | $\binom{n+k-1}{k}$ |
| Strings containing $k$ ones and $n$ zeros | $\binom{n+k}{k}$ |
| Strings with $k$ ones and $n$ zeros where no two ones are adjacent | $\binom{n+1}{k}$ |
| Catalan numbers | $\frac{1}{n+1}\binom{2n}{n}$ |
| Binomial distribution | $\binom{n}{k}p^k(1-p)^{n-k}$ |
