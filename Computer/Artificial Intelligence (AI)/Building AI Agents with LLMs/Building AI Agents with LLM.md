## Patterns

| Pattern | Idea |
|---|---|
| **Copilot Pattern** | The agent assists a human, who stays in control |
| **Research Pattern** | The agent gathers and combines information from several sources |

Related projects:

- **AutoGPT**: an autonomous agent that works toward a goal with little human input

## Selector

How the agent chooses which skill or action to run next:

- **Rule-Based Selector**: fixed rules decide the next step
- **Learning-Based Selector**: the choice is learned from data or feedback

## Skills (Decision Maker)

Skills are the actions the agent can pick from.

- **OpenAI** (LLM that does the reasoning)
- **Get Info**
  - Tech Crunch
  - Hacker News
