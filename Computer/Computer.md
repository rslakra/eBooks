## HTML Localization

- Default file is ```en-us.js``` under folder ```localization```. All the constants should be added to this file henceforth.
- Please do not add any comment in any of the localization file.
- Please follow the format ```key:value``` while adding a new constant. (Please user double quotes only to surround ```key/value``` pair. Double quote in value should be escaped by ```\```)
- There is no change in accessing value. Use the service as it is.
